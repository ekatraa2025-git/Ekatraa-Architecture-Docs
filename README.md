# Ekatraa: Architecture and Hierarchy Report (for QA)

This is a map of how Ekatraa is built, written for the testing team. It contains no source code and no secrets: environment variables are listed by name only.

Ekatraa is an event-services marketplace for weddings, pujas, festivals, corporate events and birthdays. **Customers** use the User App to book **vendors**, who use the Vendor App. A Next.js **backend** sits in the middle, serves both apps and also hosts the **Admin panel**.
